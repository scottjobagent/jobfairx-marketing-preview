## Flags

1. **URL stem.** The live site is /employer/... (singular). Michael's tracker writes /employers/... for every new page and the hub rewrite. Scott checked on 9 Oct: none of Michael's written documents ask for a rename (27 mentions of /employer), and the S-005 row says "rewrite the existing hub", so the plural is treated as a typo. The previews design under /employer/... and keep every working live link. Michael to confirm, and to say whether S-006 "create /employers/pricing" means the existing /employer/hiring-event-pricing. (Decision: Michael (confirm))
2. **"Virtual" in the roadmap vs the vocabulary rule.** S-005's target term is "virtual hiring event" and S-008's URL is /employers/virtual-hiring-events ("virtual career fair software"). The product is not virtual-only and the copy rule since August bans "virtual". The page copy says "video interviews on JobFairX"; the URL and target term are left exactly as Michael wrote them. Title tags for S-005 and S-008 need Michael's call. (Decision: Michael)
3. **Source label mismatch.** The brief's third link, labelled "Walkthrough: Candidate journey and event experience", opens Michael's "Employer content plan for JobFairX: what we found and what to build". That document was reviewed in full. No candidate-journey walkthrough document was available; the candidate process on the pages comes from the product (candidates request, employers accept, accepting confirms). (Decision: Scott)
4. **Verticals with no event type.** S-009 security, S-010 warehouse, S-014 driver/CDL and S-015 retail/hospitality match no JobFairX event type, and the plan never says which event those pages sell. The vertical template is shown on S-011 healthcare, which maps to a live event type and calendar filter. S-012 veteran and S-013 diversity are parked by Michael on the militaryx.com and diversityx.net questions. (Decision: Scott)
5. **/hire/{city} data gates.** Michael's Workstream C needs candidate registrations by city and employer registrations by event before any number can show (250+ candidates, 3+ employers), permission to show local logos, and an answer on a free tier. The preview uses the spec's own Houston example strings and shows three national logos, the spec's fallback. (Decision: Scott)
6. **/hire/{city}/{vertical} has no block spec.** The 580 V-rows exist in the tracker with a URL and a search term, but no document lists what the page contains. The preview mirrors /hire/{city} narrowed to one vertical and should not be built until Michael specifies it. (Decision: Michael)
7. **Owner column is blank.** Every tracker row has Status "To do" and an empty Owner. The inventory shows Michael's "Who builds it" column (Dev + copy, Dev, Human-written, Programmatic) as the owner. (Decision: Scott)
8. **"Interview on the day" copy.** Workstream C's fixed Speed line reads "Interview on the day. Post-event reporting the next morning." It is kept verbatim on /hire/{city}. Everywhere else the pages say interviews run before, during and after the event, which is how the product works. (Decision: Michael)
9. **Difference table kept verbatim.** The hub's "This isn't a job board" table is the live site's wording, signed off by Scott in August, including "Interviews auto-scheduled". That line is accurate only with auto-accept turned on; with it off, the employer accepts each request. Kept as the live decision stands; raise if it should change. (Decision: Scott)
10. **Logo wall.** The logo strip uses the live page's organisation names as text tiles. The August handoff recorded that some live technology logos were unverified; the names were not re-verified here. (Decision: Scott)
11. **Hub target term and title.** The live title "Hiring Event Platform for Employers | JobFairX" is kept. Michael's tracker gives the hub the target term "virtual hiring event"; see flag 2. (Decision: Michael)
12. **Pricing page sub-copy.** The live pricing sub-line says "select in-person or video interviews". The preview says "in-person, video, or phone interviews" to match the product. One-word change, flagged because the live line was deliberate in August. (Decision: Scott)
