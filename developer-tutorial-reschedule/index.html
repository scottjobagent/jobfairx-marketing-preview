Point the site at it

The video on jobfairx.com/employer is a YouTube embed, not a self-hosted file. The MP4 never goes on the web server — swap the video id in the hero iframe and you're done.

While you're in that element, three fixes that have been outstanding. All on the same iframe:

Served today

<iframe id="hero-video" class="aspect-video w-full"
        src="https://www.youtube.com/embed/QuRalPnpPLA?autoplay=1&mute=1&playsinline=1&rel=0"
        title="JobFairX product overview" frameborder="0"
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; web-share">

Should be

<iframe id="hero-video" class="aspect-video w-full"
        src="https://www.youtube.com/embed/NEW_VIDEO_ID?playsinline=1&rel=0"
        title="JobFairX product overview" frameborder="0"
        sandbox="allow-scripts allow-same-origin"
        allowfullscreen
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; web-share">
ChangeWhy
sandbox=…Stops click-through to YouTube from the logo, channel avatar, title and “Watch on YouTube”. This attribute is the only thing that does it.
allowfullscreenMust be in the server-rendered HTML. Script currently adds it after hydration, so DevTools shows it and it looks right — but a frame's permissions resolve at load, so the fullscreen button is inert today.
drop autoplay&muteSo it plays with sound when a visitor starts it. Unmuted autoplay is impossible in every browser — don't try to restore it.

The same sandbox attribute is wanted on the other two embed locations: /employer/demo, and the /employer/job-fairs/{state}/{city}/next-{type} template (one template, 1,760 pages).

One trap that will undo your work

build-event-detail.py regenerates employer-event-detail.html from a deliberately un-sandboxed live capture and contains zero iframe logic, so it will silently revert the sandbox patch the next time it runs. build-employer-home.py and build-event-healthcare.py were both patched for this; that one was not. Patch it before the next build, or re-apply after.
